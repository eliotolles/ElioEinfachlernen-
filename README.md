
### Detailed review update
Mock exams now explain every objective answer using source keys and supplied text/transcripts, including distractors and listening traps. Missing source keys remain ungraded. Reviews are batched with saved partial results and retry of missing sections. Writing uses the same shared detailed evaluator as standalone writing: practice criteria, requirements, exact errors and rules, prevention, every sentence, corrected response, model and alternative expressions. Speaking includes richer turn corrections and a saved full-conversation review. Explanation language follows settings; pronunciation is not inferred from transcripts. AI feedback requires user API configuration; live API quality and browser speech support depend on provider/browser.

### Grammar imported-material workflow
Removed built-in grammar lessons entirely. Grammar starts empty and uses only per-user imported collections. AI extracts individual topics and retains source pages, groups continuations, and creates topic folders. Sparse topics can receive clearly labeled AI theory additions and up to six generated exercises with AI answer provenance. Extracted source remains separate and source answer keys are not invented. Users review topics/JSON before saving, and may enrich any topic again. Enrichment errors preserve original extracted material and can be retried per topic; account changes cancel import. Import requires configured AI APIs (Gemini for scanned PDFs/images). No real provider or browser UI test was performed for this update.

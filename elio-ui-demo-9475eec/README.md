# Elio Einfach UI demo

A static, UI-only demo based on the Elio Einfach interface at commit `9475eec`.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist/` directory with any static HTTP server.

## Included interactions

- Multi-step exam planning popup (sample data only)
- Full day, week, and month schedule views
- Daily study route with a per-day check-in
- Day-specific vocabulary, grammar, reading, and listening cards
- Demo-only completion progress stored in browser `localStorage`
- Responsive dashboard and subtle 3D hover lift on home-page cards

No real account, API, database, or learner data is connected. The study progress is saved only in the current browser.

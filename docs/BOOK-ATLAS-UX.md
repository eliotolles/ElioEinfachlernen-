# Elio book navigation

Base: `migrate/vercel` at `1a24c7d5131065029e83d72941c0b4600fad718b`.

The interface now uses one multilingual destination catalogue for the contents,
desktop programme menu, mobile programme menu, opening-page links and chapter
breadcrumbs. The existing URLs and all learning modules remain authoritative.

- Four parts: language foundations, practical German, exams/review, personal pages.
- Contents search and a keyboard-accessible quick index (`/`, Escape to close).
  This searches destinations, not private document content or the database.
- Actual unfinished writing, grammar and exam state appears as bookmarks on the
  contents page when those records have been loaded. No sample learning progress
  or invented totals are stored or shown in production.
- Related chapters are available above each module. Import controls, editors,
  feedback and media retain their existing DOM nodes and handlers.
- Detail hashes generated by a child module also update the main address bar.
  History navigation reuses the existing module document, drafts and answers.
  Messages from unknown origins/windows or inactive frames cannot change it.
- Covered root controls are inert while a module frame is visible, and their
  previous inert state is restored when returning to the root document.

No database writes, schema migrations, AI prompts, grading criteria, answer keys,
provider routing, source content, ownership rules or import rules were changed.
No paid services or new dependencies were added.

## Validation and limits

Vercel build succeeds. Catalogue/search, multilingual labels, admin visibility,
module reuse, detail-history synchronisation and startup-without-UI-flash are
covered by tests. The full suite has five pre-existing database-fixture failures
(`app_users` missing in admin-delete and Gmail tests), reproduced on the clean
base commit; these tests and backend implementations are untouched.

Authenticated visual verification needs an Elio session. The production browser
currently shows the login cover. Cloud Browser also refuses `file:` preview URLs;
no claim of live visual or cross-device acceptance is made from local fixtures.

Deployment should use the existing Vercel branch configuration. Do not replace
the older `main` with a stale checkout or move the production database.
